[Github repo](https://github.com/amanda-yap/cli-dashboard)

I made a personal dashboard that is run in the command line.

![dashboard](/images/dashboard.png)

I wanted an offline dashboard and initially thought of making a desktop app, but I thought that would be too excessive. The only other offline interface I could think of was the terminal, so I made a terminal dashboard, using python and the Rich library. 

It was a fun process! I had highly underestimated the visual capabilities of the terminal. Thankfully, the Rich documentation was also clear and easy to follow.
